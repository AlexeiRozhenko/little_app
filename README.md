# SAME PAGE — локальный запуск (Python + Vue.js + Supabase)

Маленькое приложение для двоих: каждый день один и тот же вопрос, ответы скрыты,
пока оба не ответят, потом — reveal, эмоции, реакции, комментарии и общий архив.

## Как устроено (максимально просто)

```
Браузер (Vue 3 из CDN, без сборки)
   │  вход/регистрация ──────────────► Supabase Auth
   │  все данные: /api/* + JWT
   ▼
FastAPI (backend/main.py)  ── service-role key ──► Supabase Postgres + Storage
```

- **Никакого npm/Node.** Vue и supabase-js подключаются с CDN, фронтенд отдаёт сам FastAPI.
- **Приватность на уровне базы.** На всех таблицах включён RLS *без политик* — браузер
  с anon-ключом не может прочитать ни одной строки. Все данные идут через backend,
  который проверяет членство в комнате и правило «ответ друга виден только после reveal».
- **Атомарность в SQL-функциях:** создание вопроса дня (без дублей), вход в комнату
  (максимум 2 человека), отправка ответа + reveal.
- Фото лежат в **приватном** bucket, показываются по подписанным ссылкам на 1 час.
- «Realtime» — простой опрос сервера каждые 10 секунд на экране Daily.

```
.env.example         ← шаблон ключей
supabase/schema.sql  ← таблицы, RLS, функции, bucket, 30 вопросов
backend/main.py      ← весь API (FastAPI)
backend/requirements.txt
frontend/index.html, app.js, style.css
```

## Что нужно

- Python **3.10+** (`python3 --version`)
- Бесплатный аккаунт на https://supabase.com

> **macOS без Python:** если `python3 --version` предлагает установить «Command Line Developer Tools» —
> Python не установлен. Проще всего скачать установщик **Python 3.12** с https://www.python.org/downloads/macos/
> и запустить его (после установки откройте новое окно терминала). Node.js/npm **не нужны**.

## Шаг 1. Создать проект Supabase

1. https://supabase.com/dashboard → **New project** → придумайте пароль БД → регион поближе.
2. Подождите 1–2 минуты, пока проект создастся.

## Шаг 2. Создать базу

1. В проекте: **SQL Editor** → **New query**.
2. Скопируйте туда всё содержимое `supabase/schema.sql` → **Run**.
3. Должно быть «Success. No rows returned». Проверить: **Table Editor** — появятся таблицы,
   в `questions` — 30 вопросов; **Storage** — bucket `answer-media` (private).

## Шаг 3. Настроить вход по email

**Authentication → Sign In / Providers → Email:**
- Для локального теста проще всего **выключить «Confirm email»** — тогда регистрация
  сразу логинит. (Если оставить включённым — подтверждайте письмо и потом входите.)

**Authentication → URL Configuration:**
- **Site URL:** `http://localhost:8000`
- **Redirect URLs:** добавьте `http://localhost:8000` (нужно для письма «сброс пароля»).

## Шаг 4. Ключи → файл `.env`

**Project Settings → API Keys** (вкладка **Legacy API keys** — самый надёжный вариант):
- `anon` `public` → это `SUPABASE_ANON_KEY`
- `service_role` `secret` → это `SUPABASE_SERVICE_ROLE_KEY` (**никому не показывать**)

**Project Settings → Data API** → **Project URL** → это `SUPABASE_URL`.

В корне проекта:

```bash
cp .env.example .env
```

Откройте `.env` и вставьте три значения.

## Шаг 5. Установить зависимости

```bash
python3 -m venv .venv
```

```bash
source .venv/bin/activate
```

(Windows: `.venv\Scripts\activate`)

```bash
pip install -r backend/requirements.txt
```

## Шаг 6. Запустить

```bash
uvicorn main:app --reload --port 8000 --app-dir backend
```

Откройте **http://localhost:8000**

Остановить — `Ctrl+C`. В следующий раз достаточно `source .venv/bin/activate` и команды запуска.

## Как проверить вдвоём на одном компьютере

Сессия входа хранится в браузере, поэтому второго пользователя открывайте в **окне инкогнито**
(или в другом браузере).

1. Окно 1: **Sign up** (Аня) → **Create room** → скопируйте invite-ссылку.
2. Окно 2 (инкогнито): вставьте ссылку в адресную строку → **Sign up** (друг) → вы автоматически
   в комнате. (Или после входа вставьте ссылку в поле «Have an invite?».)
3. Окно 1: нажмите «I sent it — refresh» → открывается **Daily**.
4. Оба видят один и тот же вопрос. Выберите эмоцию → напишите ответ → добавьте фото → **Send**.
5. Пока друг не ответил — его ответа не видно (ни в UI, ни через API). После второго ответа
   в течение ~10 секунд у обоих открывается reveal с анимацией.
6. После reveal — эмоция «after reading», реакции, комментарии. День попадает в **Archive**.
7. **Play** — общий XP, уровень, streak и достижения.

Проверка, что третий не войдёт: третий аккаунт по той же ссылке получит «This room already has two people».

## Что реализовано

| Раздел | Что есть |
|---|---|
| Auth | регистрация, вход, выход, сброс пароля (Supabase Auth) |
| Комната | создание, часовой пояс комнаты, invite-ссылка (7 дней), строго 2 участника |
| Daily | вопрос дня по часовому поясу комнаты, без повторов пока пул не кончится |
| Ответ | текст + до 4 фото (JPG/PNG/WebP, до 8 МБ, проверка по содержимому файла), черновик, блокировка после отправки |
| Эмоции | 3 этапа: при виде вопроса, во время ответа, после прочтения |
| Reveal | атомарно в БД, анимация переворота карточек |
| После | реакции-эмодзи, комментарии |
| Archive | список дней, поиск, фильтр по категории, детальная страница |
| Play | XP (сервер, без накрутки), уровни, streak, достижения |

## Частые проблемы

- **`Missing SUPABASE_URL in .env`** — не создан `.env` или он не в корне проекта.
- **«Your session has expired»** — выйдите и войдите заново.
- **`Invalid API key` при старте** — перепутаны ключи или используется новый `sb_secret_…`
  со старой версией библиотеки; возьмите ключи из вкладки *Legacy API keys*.
- **«No active questions in the database»** — не выполнен `schema.sql`.
- **Ошибка загрузки фото** — проверьте, что bucket `answer-media` создан (Шаг 2).
- **Не приходит письмо** — встроенная почта Supabase ограничена несколькими письмами в час;
  для локального теста выключите «Confirm email».
- Добавить свои вопросы: **Table Editor → questions → Insert row**
  (`category`, `depth` = `light` / `medium` / `deep`).
